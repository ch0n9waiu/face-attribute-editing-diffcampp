# Face Attribute Editing with Diff-CAM++ and Adaptive Fusion

## Описание

Данный репозиторий содержит исходный код, разработанный в рамках диссертационного исследования:

> **«Метод селективного изменения атрибутов лица на основе модифицированной дифференциальной активации и адаптивного слияния для обработки изображений»**

Исследование посвящено селективному изменению атрибутов лица на основе GAN-инверсии с сохранением деталей исходного изображения.

Основное внимание в данном репозитории уделено реализации и обучению сети подавления артефактов, возникающих после редактирования и слияния исходного и модифицированного изображений.

В разработанном методе используются следующие основные компоненты:

- GAN-инверсия и семантическое редактирование изображений;
- модифицированный модуль дифференциальной активации **Diff-CAM++**;
- адаптивное семантическое слияние;
- сеть подавления артефактов на основе **MAResU-Net**;
- семантическая сегментация областей лица.
